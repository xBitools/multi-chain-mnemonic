# Address Derivation / 地址派生

**HD Wallet Derivation | Address derivation paths | 分层确定性钱包**

## Overview

Bitools uses standard hierarchical deterministic (HD) derivation to generate addresses from your mnemonic.

### Supported Standards
- BIP-39 (Mnemonic)
- BIP-32 / BIP-44 (Derivation paths)
- Chain-specific paths for EVM, Bitcoin, Solana, TRON

## What You Get
- Multiple addresses per chain
- Standard derivation path support
- Clear display of derived addresses
