# Multi-Chain Derivation / 多链地址派生

**Multi-chain derivation | 多链派生 | EVM / BTC / SOL / TRX**

## Overview

From a single BIP-39 mnemonic, Bitools can derive addresses across multiple blockchain networks simultaneously.

### Supported Derivation
- **EVM chains**: Ethereum, BNB Chain, Base, Arbitrum, etc.
- **Bitcoin**: Legacy, Nested SegWit, Native SegWit, Taproot
- **Solana**: SOL addresses
- **TRON**: TRX addresses
- More chains continuously added

## Key Benefits
- One mnemonic → All chain addresses
- Perfect for cross-chain asset management
- No need to switch tools for different networks

## Use Cases
- Discover all addresses belonging to one seed
- Manage multi-chain portfolios
- Prepare for cross-chain operations
