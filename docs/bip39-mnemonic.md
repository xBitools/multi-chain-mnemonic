# BIP-39 Mnemonic / 助记词支持

**BIP-39 Mnemonic | 12-24 word mnemonic | 助记词钱包**

## Overview

Bitools Mnemonic Wallet fully supports the BIP-39 standard.  
Enter any valid 12, 15, 18, 21 or 24-word mnemonic to start derivation.

### Key Features
- Support for 12-24 word BIP-39 mnemonics
- Standard English wordlist compatibility
- Instant validation of mnemonic phrases
- Secure handling of seed phrases

## Why BIP-39?

BIP-39 is the most widely used standard for generating hierarchical deterministic (HD) wallets.  
Almost all major wallets (MetaMask, Trust Wallet, Phantom, TronLink, etc.) use BIP-39.
