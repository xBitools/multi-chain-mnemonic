# Security / 安全说明

**Mnemonic security | Private key safety | 助记词安全**

## Important Security Notes

- Never share your mnemonic with anyone
- Only use this tool on trusted devices
- Prefer offline / local usage when handling real funds
- Bitools does not store or transmit your mnemonic

## Best Practices
- Double-check the website URL (bitools.pro)
- Clear browser data after use if on a shared computer
- Consider hardware wallets for large amounts
- Keep multiple secure backups of your mnemonic
