# Wallet Recovery / 钱包恢复

**Legacy wallet recovery | 钱包恢复 | Recover from mnemonic**

## Overview

Lost access to your old wallets?  
As long as you still have the 12-24 word mnemonic, Bitools can help you recover every derived address.

### Key Features
- Restore addresses from any valid BIP-39 mnemonic
- Support for legacy and modern derivation paths
- Multi-chain recovery in one place
- Ideal for forgotten or old wallets

## Common Scenarios
- Recovering wallets created years ago
- Finding addresses you no longer remember
- Migrating from old wallet software
- Emergency recovery when only the mnemonic is available
